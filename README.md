## להציג מהמחשב, בלי אינטרנט

1. **Code → Download ZIP** (או `git clone`), ולחלץ.
2. לחיצה כפולה על `Slides.html` (Chrome או Edge). בלי התקנה, בלי שרת.
3. `F` מסך מלא · חץ ימינה / רווח / קליק = השקף הבא · חץ שמאלה = הקודם · מספר + Enter = קפיצה לשקף ·
   `R` = להריץ שוב את האנימציה של השקף.

`Lecture outline.pdf` — הנושאים, שקף אחרי שקף.
